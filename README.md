## 💎 Design System & Experience Architecture

Unlike generic AI-templated developer websites with excessive neon cyan glows and purple cards, this portfolio adheres to an **architectural, human-designed aesthetic**:

- **Color System:** Warm obsidian foundation (`#0D0E12`), matte dark structural surfaces (`rgba(20, 22, 29, 0.72)`), and high-intent **Engineered Amber** accents (`#F59E0B`).
- **Tactile Magnetic Cursor:** Pure hardware-accelerated cursor with spring physics that morphs to clickable boundaries.
- **Tactile Micro-Audio Engine:** Subtle sound cues built with the native **Web Audio API** (toggleable via the top navigation bar).
- **Dual Experience Modes:**
  - **Continuous Stream Mode:** High-fidelity interactive scroll with layered parallax depth and magnetic section snapping.
  - **Presentation Deck Mode (`Press D`):** 6-slide executive keynote viewer built for fast recruiter and hiring-manager presentations.
- **Recruiter 60-Second Dossier (`Press R`):** Instant-access modal detailing key metrics, 4 pillars of engineering competence, and verified direct contact channels.
- **Signal Transmitter:** Direct contact system with verified delivery confirmation and seamless mail client relay.

## 🚀 Getting Started

### Prerequisites
- Node.js (version 18+ or 20+ recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/geeteshgollapalli/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   The application will be live at `http://localhost:3000` (or `http://localhost:5173`).

4. **Type-check and lint:**
   ```bash
   npm run lint
   ```

5. **Create a production build:**
   ```bash
   npm run build
   ```

6. **Preview the production build:**
   ```bash
   npm run preview
   ```
